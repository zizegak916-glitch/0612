# Privacy

IPBatchInspector has no project-operated analytics or backend.

When you start a check, your device contacts the selected public intelligence providers and those providers can observe the queried IP address, your current exit address, request metadata and timing. An exit-IP check necessarily sends a request to an external echo endpoint. An AI entrance or real subscription test contacts the named AI/custom service directly. A detailed test also makes a TLS connection to the exact target IP and explicit port (443 by default), so that target can observe the connection.

Subscription text may contain credentials. The cross-platform core keeps downloaded text in memory, returns only redacted node metadata, and does not write raw content to scan exports. The Android client additionally encrypts saved subscription URLs and API keys with Android Keystore. CLI shell history is outside the application's control; prefer `--url-file` or standard input on shared systems rather than placing a sensitive subscription URL directly on the command line.

Real mode sends only parsed node display names to a controller on the same device and never copies subscription passwords, UUIDs or node keys into controller requests. Controller secrets stay in process memory and are excluded from result storage. Automated site probes use fresh/anonymous sessions without browser cookies or account credentials; opening actual browser tabs is a separate user choice and those tabs use the browser's own privacy/login state.

CSV/JSON exports may contain IP addresses, ASN, organization, approximate location, node display names and provider evidence. Review them before sharing.
